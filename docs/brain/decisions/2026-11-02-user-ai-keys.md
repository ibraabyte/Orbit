# قرار: كل مستخدم يربط ذكاءه الاصطناعي بمفتاح API — 2026-11-02

- كل مستخدم يختار المزود (Claude أو OpenAI أو Gemini أو OpenRouter) ويحفظ مفتاحه مشفّرًا في جدول `ai_connections` مع الموديل وتعليماته.
- السبب: كان مفتاح الخادم واحدًا للجميع، فصاحب الخادم يدفع عن الكل. الحساب نفسه يكفي كمساحة خاصة، فلم نبنِ جدول workspace.
- `ANTHROPIC_API_KEY` على الخادم صار للأدمن فقط، ويتقدم عليه مفتاح الأدمن الخاص إن ربطه.
- قائمة المزودين ثابتة بلا روابط مخصصة، حتى لا يصل مستخدم إلى شبكة الخادم الداخلية.
- الموديل إجباري لغير Claude، لأن أسماء الموديلات تتغير كثيرًا.
- لا نحفظ الربط قبل نجاح طلب صغير حقيقي بالمفتاح والموديل.
