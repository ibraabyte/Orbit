# الاستخدام اليومي بالعربي

افتح جلسة جديدة داخل مجلد المشروع وشغّل Docker Desktop. يمكن استخدام نفس الرسائل في Codex وClaude Code.

## بداية الجلسة

> ابدأ جلسة Project Brain لهذا المشروع ورد علي بالعربي. اقرأ تعليماته وافحص الفرع وHEAD والتعديلات والتجهيز دون تغييرها. اسحب السياق والمهام عبر المشغّل، ثم اقرأ نقطة التوقف والتسليم والقرارات وقارنها بالعمل المحلي غير المدموج. قل لي وين وقفنا وما الخطوة التالية. حافظ على عملي الموجود.

```sh
BRAIN="$HOME/Library/Application Support/ProjectBrain/Orbit/bin/brain.py"
/usr/bin/python3 "$BRAIN" context-pull
/usr/bin/python3 "$BRAIN" tasks-pull
/usr/bin/python3 "$BRAIN" bd ready --json
```

## نهاية الجلسة

> احفظ نقطة توقف بالعربي: ما أنجزناه، القرارات، الاختبارات الفعلية، الناقص والخطوة التالية. حدّث التوثيق والتسليم ومهمة Beads، وانشر فقط الملفات المراجعة المقصودة دون تجهيز عملي الآخر أو نشر التزاماته. ارفع تاريخ المهام منفصلًا ووضح ما وصل للفرع المعتمد وما بقي محليًا أو على فرع مراجعة.

```sh
/usr/bin/python3 "$BRAIN" tasks-push
```

لا يشغّل أمر رفع المهام رفع Markdown. ملاحظة MCP محلية إلى أن يُراجع نصها وينشر. عند الانتقال إلى أداة أو جهاز آخر انتظر التسليم، ثم نفذ بداية الجلسة من جديد، ومرّر رابط الفرع/PR للعمل غير المدموج. كاتب واحد؛ توقف على التعارض. ليست هذه الخطوات تلقائية عند فتح الأداة أو إغلاقها.

Projects ينسخ المصدر Book إلى mini فقط؛ لا تعتبر تحرير المصدر من الجهازين حرًا أو آمنًا بالتزامن. قواعد البيانات تبقى مستقلة ولا تنسخها عبر المزامنة.
