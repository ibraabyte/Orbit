# Orbit: نظرة عامة مؤكدة

مرجع الفحص المحلي: `ae1dddb0cf4fe862ce3dd21afae1118113f21e6e` على الفرع `claude/project-thread-3q558v`.

- Orbit تطبيق شخصي لإدارة اليوم على iPhone وAndroid.
- النسخة الحالية تستخدم Expo وExpo Router وReact Native وTypeScript.
- يستخدم التطبيق Supabase للمصادقة وPostgres، مع عميل واحد يحفظ الجلسة عبر AsyncStorage.
- توجد شاشات وعناصر للمهام والتركيز والتخطيط والإعدادات، ومنطق مشترك لمجالات الحياة في `src/lib/`.
- README وسجل Git يذكران انتقال التطبيق من Next.js/PWA إلى Expo؛ نسخة الويب محفوظة في الوسم `web-final`.
- جزء من الوثائق الأقدم، ومنها `PRODUCT.md` و`APP_PAGES.md`، ما زال يصف PWA ومسارات الويب.
  استخدمها لفهم النية أو التاريخ، وافحص الكود الحالي قبل اعتمادها كخريطة للتطبيق.

المصادر: [README](../../README.md)، [الحزم والأوامر](../../package.json)،
