# الربط المحلي للمعرفة والمهام

- المشروع `orbit`؛ الخادم المحلي `orbit-basic-memory` في Codex وClaude.
- [Basic Memory 0.24.1](https://github.com/basicmachines-co/basic-memory/releases/tag/v0.24.1)، و[Beads 1.3.2 / Dolt 2.2.0](https://github.com/gastownhall/beads/releases/tag/v1.3.2). تم التحقق من الإصدارات الرسمية والصورة القائمة قبل التعميم.
- صورة `madar-project-brain-tools:local` مشتركة بين المشاريع؛ لكل مشروع بياناته. لا تبن صورة أخرى أو تهيئ بيئة تطبيق لهذا الربط.
- جذر التشغيل المحلي: `~/Library/Application Support/ProjectBrain/Orbit` على كل جهاز، خارج كل مجلدات Syncthing.
- `notes/orbit` نسخة Markdown؛ `state/basic-memory` للإعداد والفهرس المحلي، و`beads/.beads` لقاعدة المهام، و`beads-remote.git` وسيط تاريخ Git. لا تدخل هذه الملفات في Git المصدر.
- `config.json` المحلي يحدد المصدر الحقيقي والمرجع المعتمد وفرع التهيئة ومسار Brain واسم المشروع. لا ينسخ إلى Git؛ الإعداد المصاحب لكل مشروع مختلف.
- المصدر المعتمد `main`؛ فرع مراجعة الذاكرة `chore/project-brain`. يشترط المشغّل علامة هوية مطابقة، فيستخدم التهيئة المراجعة ثم ينتقل للفرع المعتمد بعد الدمج والجلب.
- `context-pull` يجلب هذين المرجعين فقط ثم يفهرس Markdown. `refresh` لا يجلب. لا يبدّل أي منهما فرع العمل ولا يدمجه، ولا يغير التجهيز.
- لا يفهرس المشغّل الكود أو كل توثيق المستودع تلقائيًا: فقط Markdown داخل Brain وملفي قواعد الجلسة. لا تضف تسليمات قديمة أو ملفات بيئة أو بيانات عميل حساسة إلى النسخة المفهرسة.
- استخدم Beads من خلال المشغّل. ينتقل التاريخ الملتزم به فقط عبر `refs/dolt/data` في مستودع المشروع؛ كل جهاز يحتفظ بقاعدة منفصلة. تهيأ قاعدة واحدة فقط ثم يتبنى الآخر التاريخ القائم.
- Git/SSH يعملان على المضيف بالمفاتيح القائمة. حاويات Beads تستخدم وسيط `git+file://` محليًا بلا شبكة؛ لا ترى المفاتيح أو مستودع التطبيق أو منافذ منشورة.
- حالات مهام المنتج وأوامر تشغيله وإطلاقه تبقى في مصادرها الأصلية. لا يستورد هذا الربط قوائم المهام أو يعطي موافقة نشر منتج.
- تحمي تجاهلات Projects بيانات Git وBeads وBasic Memory للمستودع. تبقى أدوار المزامنة كما هي؛ لا تنقل قاعدة Dolt/SQLite حية بين الجهازين.
