# تسليم تهيئة الذاكرة المشتركة

المشروع `orbit`. هذه لقطة تهيئة تحت الفحص وليست إعلان اجتياز الاختبار بين الجهازين.

المؤكد عند كتابة هذا الالتزام: المشغّل العام راجعه عامل مستقل واجتاز 33 اختبارًا داخل الصورة القائمة على كل جهاز. حُفظت أدوار Syncthing وتأكد تجاهل بيانات Git للمستودع. لم يغيّر جلب المراجع الفرع أو HEAD أو بايتات التجهيز وقت العملية.

لا تُفهرس بيانات التطبيق أو الأسرار أو التسليمات الخام. تبقى حقائق المنتج مستندة للعينة المحلية الموثقة وتبقى التغييرات غير المنشورة خارج هذا الالتزام. تنشر ملفات الذاكرة فقط للمراجعة.

تُستكمل الفهرسة وربط العميلين واختبار الملاحظة والمهمة بعد هذا الالتزام، ثم يُحدّث هذا التسليم بنتائج التنفيذ الفعلية ومعرفاته.

التالي: اقرأ [الحالة الحالية](../current-state.md) و[الاستخدام اليومي](../daily-use.md)، وافحص الحالة الفعلية قبل الاستمرار.
