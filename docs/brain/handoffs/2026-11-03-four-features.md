# تسليم: الميزانية وملخص الصباح واسأل Orbit والويدجت — 2026-11-03

## المنجز

- **الميزانية الشهرية:** حدّ لكل فئة في كل شهر، ونسخ الشهر الماضي بضغطة، وتنبيه عند 80% و100%. جدول `budgets` بالترحيل `0008`.
- **ملخص الصباح:** بطاقة في Today ومسار `POST /assistant/brief`، وتنبيه صباحي يُضبط وقته من الإعدادات، وأسطر محلية بديلة عند عدم وجود ذكاء اصطناعي.
- **اسأل Orbit:** شاشة `/ask` ومسار `POST /assistant/ask`. لا يُرسل شيء قبل الموافقة، والانسحاب من الإعدادات. ملخص الصباح يتبع الموافقة نفسها.
- **ويدجت iOS:** عبر `expo-widgets`، ويعرض مهام اليوم والصلاة القادمة وزر Capture. يخفي العناوين إذا كان قفل Face ID يعمل فعلًا.
- رقم نسخة التطبيق صار 0.4.0، لأن الويدجت يحتاج بناءً أصليًا جديدًا.

## الفحص

- `npm run verify` نجح بـ303 اختبارات، و`pytest` نجح بـ287 اختبارًا، و`ruff` نظيف.
- نُفذ العمل بايجنتات، ولكل مهمة مراجعة، ثم مراجعة شاملة وجولة إصلاح.
- شوهد الويدجت على المحاكي بحساب غير مسجّل وبيانات تجريبية.
- لم يُجرَّب أي شيء على الهاتف، ولا بحساب ذكاء اصطناعي حقيقي، ولم يُشغَّل الويدجت بحساب مسجّل.

## الناقص والخطوة التالية
